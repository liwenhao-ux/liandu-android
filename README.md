# LOCK IN

一个轻量化、低耗电的学习专注与复盘 Android App，采用低饱和主题色与日系线稿视觉。

当前版本：`1.9.3 (45)`

版本约定：每次功能调整或问题修复都同步递增 `versionCode` 和 `versionName`。

## 已实现

- 今日重点：每天选择一个任务、习惯或手动目标作为主目标
- 专注目标：开始前明确本次专注要完成什么
- 专注复盘：记录结果、专注质量、问题、下次行动和分心次数
- 专注历史：查看每次专注的目标、结果与复盘
- 二次元视觉：原创角色线稿融入重点卡片、专注页与统计页，不遮挡学习信息
- 交互质感：即时卡片按压、克制无弹跳回弹和方向一致的详情页转场

- 今日学习任务：一次任务与长期习惯，支持学习类型和核心任务
- 习惯关联：具体任务可选所属习惯，专注时长自动汇总且保留历史归属
- 习惯详情：今日目标、今日累计、连续完成、今日任务和直接专注
- 任务详情：累计专注、近 7/30 天、活跃天数和最近记录
- 卡片编辑：任务详情内可编辑任务，重要日可直接编辑描述与日期
- 番茄专注：自定义专注、休息和循环轮次，默认 25 / 5 分钟、2 轮
- 状态恢复：离开页面、应用进程重启或设备重启后继续原来的番茄钟
- 锁屏状态：专注时通过无声的默认级持续通知显示阶段、轮次和动态倒计时
- 通知控制：可直接在通知栏暂停、继续或结束本轮专注
- 触觉反馈：开始、继续、暂停、结束与阶段切换使用分级震动，完成任务使用轻触反馈
- 专注结算：完成、部分完成、未完成，并记录专注质量与下一步
- Form Rating：显示评分构成、强项、短板和下一步行动建议
- 历史筛选：专注历史支持 7 天、30 天、全部范围及按任务筛选
- 手动补记：可填写并编辑日期、开始时间和时长，关联任务或习惯，重叠时主动提醒
- 减法界面：首页只突出今日重点、最多 3 项待办和最近重要日，任务新增与高级字段按需展开
- 低饱和主题：雾紫、浅苔、雾蓝、月灰四组配色，自动适配浅色与深色模式
- 功能检测：集中检查通知、音乐访问和后台电池限制，并直达系统设置
- 安全恢复：导入备份前预览任务、记录、重要日和计划数量，再确认替换
- 统计页：Form 分项、最近 7 天学习时长、今日时长、连续学习天数
- 本地存储：Room 数据库，离线可用
- 深色模式：自动跟随 Android 系统主题
- 图标导航：首页、任务、专注、统计使用图标和双字标签

## 低耗电策略

- 只在番茄钟运行或暂停时启用前台服务，结束后立即停止
- 不做复杂动画和高频刷新
- 只有专注页面运行时每秒刷新一次倒计时
- 计时状态只在开始、暂停、切换阶段等事件发生时写入 DataStore
- 锁屏倒计时由 Android 系统计时组件绘制，不在后台每秒唤醒界面
- 学习数据全部本地保存，不依赖网络
- 统计图用 Compose 基础控件绘制，不引入大型图表库
